# Caddie Voice

A phone web app that speaks golf yardages. Pick a course, see its satellite map and hole layout, and pin greens.

- `index.html` is the whole app (one file).
- Course layouts come from OpenStreetMap (© OpenStreetMap contributors, ODbL).
- Satellite imagery © Esri, Maxar.

Hosted on Netlify. Every push to `main` redeploys the site.
